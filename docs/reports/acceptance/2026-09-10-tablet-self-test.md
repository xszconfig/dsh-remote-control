## 诚实标注

- **返回导航第三级（列表→桌面）**：无头模拟器不便于验证系统返回退出 App 到桌面，此项标注**代码级**（`MainScreen`/`TabletMainScreen` 的 `PlatformBackHandler(enabled = currentSessionId == null) { platformExitApp() }` 逻辑与单测一致，未设备目验）。
- **启动冒烟通过后通知权限弹窗**：首连后弹「开启通知提醒」权限说明，测试中点了「暂不」跳过（与本任务无关，不影响三栏验收）。
- **截图**：主对话模型无图像输入，截图仅作存证未由本 agent 目检；布局/交互逐项由 dump 文本树 bounds 断言。建议用户/视觉模型复验截图。
- **旋转方向**：本次仅验证「宽度断点」两态（540dp 单栏 / 1280dp 三栏），未验证横竖屏旋转（无头模拟器旋转需另设 `wm user-rotation`，非本任务硬性项）。
