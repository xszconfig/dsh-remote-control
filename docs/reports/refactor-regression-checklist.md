# 重构后回归清单（refactor/arch-split）

> 用途：App.kt / BridgeClient.kt 纯结构拆分（`private→internal` + 整段搬移）后，随统一装机批次逐条目验。**每功能点一条**，供批次按「预期/实测/结论」打勾。
> 拆分承诺零行为变化；本清单即「零行为变化」的目验依据。
> 分支：`refactor/arch-split`；不 merge 回 main（主对话统一合并+全量门禁+集成验证）。

## P00 启动冒烟（硬断言，失败即验收失败）

- [ ] **启动冒烟**：冷启动存活 ≥5 秒，crash buffer 无本包 FATAL。（startup-smoke-test skill）

## 会话/发送/消息

- [ ] **发送 + ack**：点发送 → 消息立即上屏 + 同时间行 Loading → 服务端 ack 后 Loading 消失（IM 模式语义不变）。
- [ ] **发送失败重发**：失败消息红色 ❗，点击可重发（Pending 队列语义不变）。
- [ ] **消息气泡 Markdown 渲染**：Agent 正文代码块/表格/加粗/行号代码块横向滑动正常（Bubble/ScrollableCodeBlock）。
- [ ] **工具调用卡 / 思考卡 / 上下文行 / 命令弹窗**：显示与交互与拆分前一致。
- [ ] **「你」标签 + 时间戳**：自己消息「你」标签与时间戳显示正常（深色/浅色可见性不变）。

## 会话列表 / 队列 / 中断

- [ ] **会话列表**：按所选工作区过滤，会话卡标题/子代理副标题显示正常。
- [ ] **排队面板默认折叠**：展开/折叠交互正常。
- [ ] **中断二选一弹框**：有排队消息时中断 → 弹框（终止并清空 / 仅终止保留 / 取消）语义不变；「仅终止保留」后队列有待执行消息时自动启动新一轮消费。

## 转盘（MessageDial）

- [ ] **转盘拖拽/对齐**：拖拽、回到底部、收起钮背景（0.9）与拆分前一致。
- [ ] **转盘深色主题**：深色下转盘显示正常。

## 设置 / 主题

- [ ] **设置入口**：抽屉底部「设置」进入 SettingsScreen，返回键回退（覆盖层语义）。
- [ ] **主题三态**：跟随系统 / 浅色 / 深色 即时生效 + 持久化（重启后保持）。
- [ ] **后台保活提示**：设置页电池优化豁免申请按钮行为正常。

## 连接 / 通知 / 保活

- [ ] **连接横幅**：重连横幅、连接错误横幅、错误历史 Sheet 显示正常。
- [ ] **FGS 通知**：后台运行时结果交付通知送达；点击通知打开对应会话。
- [ ] **审批/提问弹窗**：半屏强提醒，裁决/回答后关闭；拖拽把手显示排队数量。

## 导航 / 布局

- [ ] **手机单页流**：设备页/日志页/设置页覆盖层返回键逐级回退（不跳页，铁律 3）。
- [ ] **平板三栏布局**：宽 ≥840dp 启用三栏（TabletMainScreen/TabletLeftPane），手机/横屏/折叠屏走单页流（零回归）。
- [ ] **落地页**：设备列表/手动连接/扫码连接/设备卡状态显示正常。
- [ ] **日志页**：本地/服务端日志列表、过滤片、日志行颜色正常。
- [ ] **调试面板**：调试 Tab（LSP 诊断/调试状态/调用栈/变量树）显示正常。

## 子代理嵌套浏览（#45，对齐 DSH Web，随下一批装机目验）

- [ ] **🤖N 入口 + 后代计数**：主会话右上角 🤖N（N=后代总数，含孙代）；会话卡 🤖N 同步为后代总数（与 DSH Web 语义一致）。
- [ ] **树展开/折叠**：一级子代理平铺；「有子代理的子代理」显示展开箭头 ▸ + 后代计数；点箭头展开其直接子代（缩进递增）；再点 ▾ 折叠；递归任意深度。
- [ ] **子代理会话入口**：进入子代理会话后，若其仍有孙代子代理，右上角同样出现 🤖N 下拉并可持续下钻浏览。
- [ ] **点击 vs 展开不串**：点行主体打开该子代理；点箭头只切换展开、不误触打开；展开态随切换会话重置（不跨会话串树）。
- [ ] **空态**：无子代的会话入口隐藏；（防御）展开后无节点显示「暂无子代理」。
