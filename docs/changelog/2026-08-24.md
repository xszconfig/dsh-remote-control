# 更新日志 2026-08-24 —— 项目诞生

> 两个仓库的首次提交都在今晚（bridge 22:09，app 22:08）。DSH Remote Control 立项：用手机远程控制 Mac 上运行的 DeepSeek Harness 桌面 Agent。

## ✨ 新功能（首版）

**dsh-remote-control-bridge**（服务端插件）
- DSH 远程控制 bridge 插件：WebSocket `/remote/ws` + REST 端点族（配对/设备/连接状态）
- Web UI 配对弹窗（扫码 + 候选端点下发）
- 设备配对体系（长期 token、多路由候选地址）

**dsh-remote-control**（Android 客户端）
- 完整功能版手机客户端：扫码配对、会话浏览、消息收发、审批/提问半屏交互

## 🎯 重要技术决策（架构奠基）

1. **客户端**：Kotlin Multiplatform + Compose Multiplatform（Android 真机）
2. **服务端**：bridge 以 **profile 插件**形态运行，不改 dsh-core（单向数据流、服务端投影为准）
3. **协议**：自研 JSON over WebSocket（配对/订阅/事件广播/命令），不用现成框架
4. **通信链路**：USB adb reverse / 局域网 / Tailscale 多路由并存（DSH Web 仅绑定 127.0.0.1 的约束下）
