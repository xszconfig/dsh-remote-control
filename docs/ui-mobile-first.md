# 移动端优先设计原则（项目大背景记忆）

> **大背景**：DSH Remote Control 是一个**手机端 App**（Kotlin Multiplatform + Compose，华为真机 HBN-AL00 / 1260x2844 竖屏）。所有设计，尤其是 UI 与交互，必须从手机屏幕出发。桌面端 / Web / 手机端的设计原则不一样。

## 铁律

1. 任何 UI 元素先问：**在手机小屏上合不合理**（字号、密度、触控目标、单手可达性）
2. 库/组件的**默认值必须核对是桌面还是移动预设**——不能照搬默认
3. 交互设计遵循手机惯例：返回键逐级导航、列表滚动语义、横幅表达状态变化（禁非预期跳页）
4. 空间预算思维：手机竖屏高度有限，顶部条区已约定顺序与折叠规则（Deep Diving → 任务列表 → Goal → 排队消息），面板默认收起、按需展开
